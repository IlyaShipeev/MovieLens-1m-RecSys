# MovieLens Recommender

Двухэтапная рекомендательная система на MovieLens 1M: подбор кандидатов через
Implicit ALS и ItemKNN, затем персональное ранжирование CatBoostRanker.
Проект включает временную оценку качества, сравнение с MostPopular,
эксперименты с признаками и локальное Streamlit-приложение.

## Архитектура

```text
История оценок до даты рекомендации
    → ALS: 150 кандидатов + ItemKNN: 100 кандидатов
    → удаление повторов + Popular-добивка до 250
    → признаки пользователя, фильма и retrieval
    → CatBoostRanker → top-K
```

Положительное взаимодействие - оценка 4–5. ALS обучается на бинарной user–item
матрице, ItemKNN использует cosine similarity между фильмами. Любой ранее
оценённый фильм исключается из рекомендаций, включая оценки 1–3.
MostPopular считает положительные оценки из истории и служит baseline и fallback.

CatBoost использует 11 признаков: ALS/KNN score и rank, три флага источников,
число и среднюю оценку пользователя и фильма. Настройки основного решения:

| Компонент         | Параметры                                              |
| ----------------- | ------------------------------------------------------ |
| ALS               | factors=32, regularization=0.1, alpha=1, iterations=15 |
| ItemKNN           | 50 соседей каждого фильма                              |
| CatBoost          | YetiRank, depth=6, learning_rate=0.05, 66 деревьев     |
| Воспроизводимость | seed=42, [конфиг](configs/experiment.json)             |

## Временное разделение и защита от утечек

| Этап                       | История для retrieval и признаков | Месяц правильных ответов             |
| -------------------------- | --------------------------------- | ------------------------------------ |
| Обучение CatBoost          | Строго до начала каждого снимка   | Сентябрь–декабрь 2000, четыре снимка |
| Validation                 | До 1 января 2001                  | Январь 2001                          |
| Final test выбранной модели | До 1 февраля 2001                 | Февраль 2001                         |

Все границы заданы в UTC; конец окна не включается. Для каждого снимка ALS/KNN
обучаются заново только на его прошлом. CatBoost обучен на снимках сентября–декабря;
перед февральским тестом не переобучается на январских метках.

Группа ранжирования - пользователь в конкретном месяце. Из обучения исключаются
группы с одинаковыми метками; в оценке сохраняются все пользователи выбранной когорты,
включая тех, для кого retrieval не нашёл ни одного положительного фильма.
В модель передаются только признаки: target используется отдельно как метка.

Ground truth содержит **все** положительные оценки целевого месяца, включая
фильмы, пропущенные retrieval. Основная оценка проводится на пользователях
с историей и хотя бы одной положительной оценкой в целевом окне.
Каталог для рекомендаций - фильмы, встречавшиеся в истории до cutoff.

## Результаты

Февральский test исходной модели: **347 пользователей**, одинаковая когорта,
каталог и ground truth для всех вариантов. Метрики усредняются по пользователям;
CatalogCoverage считается по всему набору рекомендаций.

| Модель                          |     NDCG@10 |   Recall@10 | Precision@10 |  HitRate@10 |
| ------------------------------- | ----------: | ----------: | -----------: | ----------: |
| MostPopular                     |     0.09135 |     0.06355 |      0.06772 |     0.31700 |
| ALS                             |     0.09880 | **0.07855** |      0.06830 |     0.33718 |
| ItemKNN                         |     0.10008 |     0.07556 |      0.06888 |     0.33429 |
| Union ALS150 + KNN100 + Popular |     0.09880 | **0.07855** |      0.06830 |     0.33718 |
| **CatBoost**                    | **0.10233** |     0.07827 |  **0.07176** | **0.35447** |

CatBoost улучшает порядок кандидатов относительно исходного Union, но выигрыш
над ItemKNN небольшой. Recall@250 Union и CatBoost одинаковый: **0.52856**,
поскольку ранжирование не меняет состав кандидатов. Статистическая значимость
разницы не проверялась. Полные таблицы находятся в [ноутбуке 06](../notebooks/06_final_testing.ipynb).

### Эксперименты

- Дополнительные признаки: 11 базовых, +popular_rank/missing-индикаторы (14),
  +пол/возрастная группа/профессия (17). January NDCG@10: **0.12999**, 0.12656,
  0.12940 соответственно. Основной набор - 11 признаков.
- Подбор гиперпараметров: **12 ALS + 4 ItemKNN + 12 CatBoost = 28 экспериментов**.
  Новые настройки улучшили January Recall@250 Union с 0.51940 до 0.53498,
  но итоговый NDCG@10 снизился с **0.12999** до 0.12895. Исходная модель сохранена основной.
- Подбор выполнялся по январю **после просмотра февральского test**. Новая модель
  не оценивалась повторно на феврале и не имеет новой независимой проверки.
  Пространство поиска, параметры и результаты представлены в [ноутбуке 05](../notebooks/05_hyperparameter_search.ipynb).

Порядок воспроизведения: подбор по январской validation → выбор pipeline с лучшим
NDCG@10 → февральская оценка. Сейчас побеждает исходный CatBoost. Ноутбук финального
теста и приложение выбирают модель по одной январской таблице и загружают её
вместе с соответствующим конфигом retrieval. Повторный просмотр февраля не является
новым независимым тестом.

## Данные и запуск

Данные: [MovieLens 1M / GroupLens](https://grouplens.org/datasets/movielens/1m/).
После клонирования скачайте и распакуйте архив MovieLens 1M. Файлы
`ratings.dat`, `movies.dat`, `users.dat` нужно поместить в корень репозитория,
рядом с [главным README](../README.md), на один уровень выше этого каталога.
Другой путь задаётся через `data_dir` в конфиге. Датасет не включён в Git.
Описание формата — в [README датасета](../README).

Из каталога movielens-reccomender, PowerShell:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e '.[notebook,models]'
.venv/Scripts/python.exe -m ipykernel install --user --name movielens-recsys --display-name "MovieLens Recsys"
```

Python 3.11+; локально проверено на Python 3.13.2. В ноутбуках используется
ядро установленного окружения. Порядок воспроизведения:

| Ноутбук                                                             | Содержание                                          |
| ------------------------------------------------------------------- | --------------------------------------------------- |
| [01 - EDA](../notebooks/01_eda.ipynb)                               | Пошаговый анализ данных, графики и календарные окна |
| [02 - Baseline](../notebooks/02_baseline.ipynb)                     | MostPopular и ranking-метрики                       |
| [03 - Retrieval](../notebooks/03_retrieval.ipynb)                   | ALS, ItemKNN, RRF и обычное объединение             |
| [04 - Ranking](../notebooks/04_catboost_ranking.ipynb)              | Снимки, CatBoost и сравнение признаков              |
| [05 - Hyperparameters](../notebooks/05_hyperparameter_search.ipynb) | Результаты 28 экспериментов и выбор по январю      |
| [06 - Final test](../notebooks/06_final_testing.ipynb)              | Февральская оценка выбранной модели                |

В 01 расчёты, графики и выводы находятся непосредственно в ячейках ноутбука;
В 04 сохраняется исходный CatBoost. В 05 сравниваются исходный и подобранный
pipeline; для нового поиска используется команда ниже. В 06 загружается
победитель по январскому NDCG@10 и рассчитываются февральские метрики.
Обученные модели не включены в Git. Для запуска демо с текущим победителем
достаточно выполнить 01–04: базовая модель будет сохранена локально.
В 05 уже доступны сохранённые таблицы 28 экспериментов; повторять поиск
для просмотра результатов и запуска текущего демо не требуется.
Запуск приложения:

```powershell
.venv/Scripts/python.exe -m streamlit run app/streamlit_app.py
```

Адрес: http://localhost:8501. Приложение показывает рекомендации, прошлую историю
и реальные февральские оценки выбранного пользователя. По умолчанию список
содержит пользователей с положительными оценками в феврале. Также можно выбрать
всех с февральскими оценками или всех с историей. Будущие оценки доступны
только для сравнения после выдачи, не для предсказаний.
Подробнее - [приложение](app/README.md).

## Ограничения

- MovieLens содержит оценки, а не показы и клики. Отсутствие оценки не означает dislike;
- У **62.9% пользователей** все оценки укладываются в сутки. Даты отражают момент
  выставления оценок, а не достоверное время просмотра фильмов.
- Основные метрики относятся к пользователям с историей; полноценный cold-start
  эксперимент и поддержка новых профилей не реализованы.
- Профили MovieLens считаются статичными в эксперименте с демографией.
