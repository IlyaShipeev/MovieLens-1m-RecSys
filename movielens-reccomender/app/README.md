# Streamlit demo

Приложение сравнивает CatBoost, Union и MostPopular для существующих пользователей
MovieLens. Доступны история оценок, top-K с названиями и жанрами, скачивание выдачи
и сравнение с реальными оценками за февраль 2001 года.

Длина выдачи K: 5, 10 (по умолчанию), 20, 50 или 100 фильмов. Выбранное K
применяется к рекомендациям, персональному сравнению и общей таблице метрик.

## Запуск

После скачивания данных, установки проекта и выполнения ноутбуков 01–04
модель будет сохранена локально. Для текущего победителя повторять подбор
не требуется: январская таблица сравнения уже включена в репозиторий.
Из каталога movielens-reccomender:

```powershell
python -m streamlit run app/streamlit_app.py
```

## Данные выдачи

История заканчивается строго до 1 февраля 2001 года. Приложение выбирает pipeline
с лучшим январским NDCG@10 из таблицы сравнения исходного и подобранного вариантов.
Сохранённый CatBoost загружается вместе с соответствующими настройками ALS/KNN;
retrieval обучается при первом открытии
и кешируется в памяти. Подготовка кандидатов и признаков общая с ноутбуками.

Февральские оценки используются только после выдачи для отображения попаданий
(оценка 4–5), Recall@K и пропущенных retrieval фильмов. Пустая оценка означает
отсутствие наблюдения, а не отрицательное предпочтение. При отсутствии февральских
оценок персональное сравнение недоступно, но рекомендации сохраняются.

В боковой панели можно выбрать пользователей с оценками 4–5 в феврале
(по умолчанию), с любыми февральскими оценками или всех с историей до февраля.
Фильтр меняет только список профилей для просмотра, а не обучение моделей.

Общие февральские метрики загружаются из таблицы, сформированной
[ноутбуком 06](../../notebooks/06_final_testing.ipynb). Новые профили пока не поддерживаются.

Архитектура, результаты и воспроизведение - в [основном README](../README.md).
